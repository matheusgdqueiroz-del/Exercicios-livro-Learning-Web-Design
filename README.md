Repositório para exercícios e estudos baseados no livro Learning Web Design. O objetivo é registrar práticas de HTML, CSS e fundamentos de web design conforme o conteúdo for avançando.

## Objetivos

- Organizar exercícios do livro.
- Praticar fundamentos de HTML e CSS.
- Registrar exemplos e anotações de estudo.
- Acompanhar a evolução no desenvolvimento web.

## Tecnologias previstas

- HTML5
- CSS3
- Git e GitHub
